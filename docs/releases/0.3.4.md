# Agent Supervisor 0.3.4

Version 0.3.4 improves process-exit reporting and supports larger service
messages.

## Fixed

- A process that exceeds its configured stdout or stderr limit now produces an
  exit receipt instead of leaving attached clients waiting indefinitely.
- Stream failures are sent to process clients as error events before the final
  exit receipt.

## Changed

- Supervisor service JSONL frames use a 16 MiB limit across the Rust, Python,
  Node.js, and TUI clients.
