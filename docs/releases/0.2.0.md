# Agent Supervisor 0.2.0

Version 0.2.0 adds a shared agent-run lifecycle and stdio MCP integrations
across Rust and Python. It builds on the process execution and WASM support in
the 0.1.x releases.

## Added

- Rust exposes `AgentRunPolicy` and `AgentRunScope` for an overall agent-run
  deadline, cancellation, and cleanup of local tool processes.
- Python exposes matching `AgentRunPolicy` and `AgentRunScope` types. Its
  OpenAI Agents SDK, Microsoft Agent Framework, LangGraph, PydanticAI, and
  Google ADK adapters use the same public scope.
- Rust can run a local stdio MCP server under process supervision and apply
  shared MCP tool-call controls.
- Python adds import adapters for stdio servers using the official MCP Python
  SDK and Prefect FastMCP. Existing server tools and MCP clients keep their
  protocol flow.
- Rust and Python API references describe the run-scope and tool-process
  lifecycles, arguments, return values, defaults, and examples.

## Behavior and limits

- The agent framework still runs agent code and model requests in the
  application process. A deadline cancels the framework operation
  cooperatively; it does not forcibly terminate in-process agent code.
- Agent Supervisor cleans up local tool processes started through its APIs.
  File, network, and resource enforcement still depends on the selected
  platform backend and policy.
- MCP adapters in this release supervise local stdio servers. They do not
  supervise HTTP transports.
- Python framework adapters and Python MCP integrations require optional
  dependencies. Install the extras for the SDKs you use; the documentation
  lists each extra.

## Validation

The Rust all-target test suite and Python unit suite pass in the repository
checkout. FastMCP-specific Python tests require the optional FastMCP extra;
they are skipped when it is not installed.
