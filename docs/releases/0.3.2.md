# Agent Supervisor 0.3.2

Version 0.3.2 aligns the package versions across the Rust crate, Python
binding, and Node.js native addon. It includes the persistent Supervisor
service and coordinator introduced in 0.3.1.

## Compatibility

- No additional public API changes from 0.3.1.
- The Python binding continues to require Python 3.9 or later.
- The Node.js native addon is distributed from a source checkout and is not
  published to npm.
