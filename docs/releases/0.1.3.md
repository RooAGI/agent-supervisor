# Agent Supervisor 0.1.3

Version 0.1.3 adds an optional WebAssembly runner to the Rust API. Native
process execution remains the default.

## Added

- The `wasm` Cargo feature, backed by Wasmi, exposes `WasmRunner` through the
  existing `ProcessRunner` interface.
- The runner supports one-shot modules with the documented JSON guest ABI,
  memory and fuel limits, and no host imports.
- Eight WASM unit tests cover ABI execution, host-import rejection, request
  policy validation, malformed modules, and input/output/resource limits.
- The Python binding remains on the native process backend; it does not expose
  the WASM runner.

## Limitations

- WASM execution does not provide WASI, host filesystem or network access,
  process creation, persistent services, MCP server supervision, or PTYs.
- A timed-out invocation may continue in its isolated blocking worker until its
  Wasmi fuel budget is exhausted.
- WASM execution remains limited to the documented guest ABI and deny-all host
  capabilities; this release does not add WASI support.

## Validation

The eight WASM unit tests and the complete Rust library unit suite pass with the
`wasm` feature enabled. The default and WASM-feature builds also compile.
