# RooAGI Sandbox 0.1.0

Initial public release of `rooagi-sandbox`.

## Included

- bounded native process execution with stdin, stdout, stderr, deadlines, and
  cancellation;
- TERM/grace/KILL shutdown and process-tree cleanup;
- Linux cgroup v2 resource containment and Landlock filesystem policy;
- Windows Job Object containment and AppContainer filesystem policy;
- macOS Seatbelt filesystem policy with explicit host-network behavior;
- shared process groups, external adoption, identity checks, lifecycle events,
  resource snapshots, and statistics;
- connected pipelines with stage-indexed failures;
- TCP, port, and HTTP readiness probes;
- Unix PTY and Windows ConPTY execution paths; and
- deterministic runner seams for orchestration tests.

## Compatibility notes

- Host networking is the supported network mode in 0.1.0.
- `NetworkMode::Disabled` is reserved and fails closed until native network
  denial is implemented.
- macOS filesystem isolation currently uses `/usr/bin/sandbox-exec`; it is not
  equivalent to a signed Apple App Sandbox helper.
- Native platform integration tests must run on Linux, macOS, and Windows
  hosts respectively.
