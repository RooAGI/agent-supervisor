# Agent Supervisor 0.3.1

Version 0.3.1 adds an authenticated client API for the persistent Supervisor
service and its service-owned workflow coordinator.

## Added

- The service exposes metadata snapshots, epoch/cursor subscriptions, process
  streams, and scoped control, reporting, and cancellation clients.
- The coordinator tracks FlowRuns, stages, task dependencies, attempts,
  processes, waiting states, and bounded evidence.
- Flowboard updates use a durable, idempotent outbox. Coordinator state and
  dispatch reservations survive service restart; unresolved launches remain
  unknown and are not automatically replayed.
- Worker tool and approval requests are attempt- and generation-scoped,
  fenced, bounded, and hidden from view-only clients.

## Limits

- The standalone service currently supports Unix-domain sockets. Windows
  process APIs remain available through the embedded library.
- Framework-specific checkpoint restoration remains owned by each framework.
  An unresolved dispatch after service restart is not replayed unless its
  completion can be verified.
- Provider smoke tests use fixtures rather than authenticated live accounts.

## Validation

The repository test suite covers service recovery, fencing, role separation,
FlowRun reconciliation, client reconnect, bounded output, and worker
cancellation. See the project test records for the complete platform matrix.
