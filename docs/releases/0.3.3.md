# Agent Supervisor 0.3.3

Version 0.3.3 adds a standalone terminal process manager and improves the
service and coordinator experience.

## Added

- A Ratatui process manager displays active and completed processes, supports
  process control, and can render a one-time snapshot without entering an
  interactive terminal loop.
- The service exposes the TUI through the existing authenticated service
  protocol, preserving the existing rendering and input loop.
- The README and API documentation describe the terminal process manager and
  the Node.js service integration.

## Fixed

- Process labels fall back to the OS process ID when metadata is unavailable.
- Windows AppContainer loopback tests retry transient failures, and service
  recovery and cancellation tests wait for process cleanup.
